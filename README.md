Save the Watermelon
Project Description
For this project, I made a simple word guessing game using Python. The computer picks a random word, and the player guesses one letter at a time.
Game Rules
The player starts with 6 watermelon slices. Each wrong guess takes away one slice. The goal is to guess the word before running out of slices.
How to Run
Open the project in PyCharm. Open the watermelon_game.py file in the src folder and run the program.
Features
The game picks random words, keeps track of guesses, checks for repeated letters and invalid answers, and allows the player to play again.
Known Issues
So far, I haven't noticed any major problems while testing the game.
